# VixHub — Android клиент для сервера

Современное приложение на **Kotlin + Jetpack Compose + Material 3** для работы с вашим Flask-сервером через Cloudflare-туннель.

## Возможности

- **Статус** — автоматическое получение актуального URL из Firebase, проверка `/health`
- **Фото** — загрузка из галереи (multipart), список, просмотр
- **База данных** — чтение / запись / merge / force / удаление по пути
- **Скрипты** — загрузка `.py`, запуск, остановка, просмотр логов
